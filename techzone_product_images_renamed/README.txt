# TechZone Periféricos — imagens de produtos

Pasta organizada com as imagens geradas para o e-commerce fictício TechZone Periféricos.

Padrão dos arquivos:

`produto_nome_cor_variacao.png`

Todos os arquivos foram mantidos em formato PNG, proporção quadrada 1:1, estilo foto de produto para e-commerce, fundo claro/branco e sombra suave.

Observação: algumas variações têm enquadramento/modelagem levemente diferente porque foram geradas como imagens independentes ou variações de cor.
